# «Прыгай выше» — игра на сайте

Игра запускается в браузере. Стрелки или A/D двигают зайчика на компьютере; на телефоне работают две кнопки и перетаскивание по игровому полю. Рекорд, имя и таблица работают в локальном режиме без настройки. Для общей таблицы всем игрокам нужен один общий проект Supabase.

## Подключить общий аккаунт и лидерборд

1. Создай бесплатный проект Supabase.
2. В Supabase открой **SQL Editor → New query**, вставь содержимое `schema.sql` и нажми **Run**.
3. В настройках проекта скопируй **Project URL** и публичный **anon/publishable key**.
4. В `game.js` настройки проекта указаны в начале файла. Если подключаешь другой Supabase-проект, замени их на значения из его Dashboard:

   ```js
   const backend = {
     url: "https://ТВОЙ-ПРОЕКТ.supabase.co",
     anonKey: "ТВОЙ-ПУБЛИЧНЫЙ-ANON-ИЛИ-PUBLISHABLE-KEY"
   };
   ```

5. В Supabase открой **Authentication → URL Configuration** и добавь `https://kreker3232.github.io/our-countdown/` в список **Redirect URLs**. Это нужно для подтверждения почты и восстановления пароля.
6. Загрузи обновлённые `index.html`, `game.js` и `schema.sql` в GitHub Pages.

Используй только публичный anon/publishable key. **Не добавляй в сайт `service_role` key** — он даёт полный доступ к базе. В Supabase включи подтверждение email для регистрации; новый игрок подтвердит почту и затем войдёт.

`schema.sql` разрешает всем читать только публичные имена и рекорды, а менять рекорд — только через функцию базы для вошедшего пользователя. Счёт обновляет рекорд только вверх. Клиентская игра остаётся уязвимой к поддельному счёту со стороны технически продвинутого пользователя; для дружеского лидерборда это обычно достаточно, для соревнования с защитой от читов нужен сервер, который сам проверяет игровую сессию.

Пока в `game.js` не указаны данные проекта, аккаунт работает как локальное имя браузера, а общий рейтинг честно помечен как неподключённый.
